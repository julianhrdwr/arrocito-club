ARROCITO CLUB — Calculadora de aliño

La app calcula el aliño como el 12% del peso del arroz cocido y reparte ese total en proporción 8:4:1 (vinagre, azúcar, sal).

Archivos:
- index.html: interfaz y calculadora
- manifest.webmanifest: datos de instalación PWA
- sw.js: caché offline
- icons/icon.svg: icono

Para probar en computadora: abrir index.html en el navegador.
Para instalar como app desde Android: publicar esta carpeta en un hosting HTTPS (por ejemplo GitHub Pages), abrir la URL en Chrome y elegir menú ⋮ > Instalar aplicación / Añadir a pantalla de inicio.

Para generar un APK nativo, este proyecto web debe envolverse con Android Studio/Capacitor o una WebView y compilarse con Android SDK. Este paquete no incluye un APK compilado.
